# PDS Actividad 01 - Patrones creacionales (Grupo 07)

Repositorio: https://github.com/Dalefra98/PDS_Actividad_01_Grupo07

- `Escenario01_FactoryMethod/`: registro de vehículos y cálculo de matrícula (Factory Method).
- `Escenario02_Builder/`: registro de activos fijos (Builder).
- `Diagramas_UML/`: los dos diagramas de clases juntos, en `.png` y en `.drawio` editable.

Cada carpeta contiene el código Java, el diagrama de clases (`.drawio` editable en https://app.diagrams.net y su exportación `.png`) y una guía HTML interactiva
(abrir el `.html` en el navegador) que ejecuta el escenario paso a paso y explica cada método.

## Ejecutar (Java 17+)

```
cd Escenario01_FactoryMethod
javac Escenario01_FactoryMethod.java && java Escenario01_FactoryMethod

cd ../Escenario02_Builder
javac Escenario02_Builder.java && java Escenario02_Builder
```
